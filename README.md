# 食光机 · 美食 APP 框架 v0.1

> 帮助你更好的做饭

一个静态网页框架：欢迎页 → 点击「开始使用」→ 选择食谱。

## 运行

直接双击 `index.html` 打开，或启动本地服务：

```bash
python -m http.server 8300
# 浏览器访问 http://127.0.0.1:8300
```

## 目录结构

```
index.html          入口页面（5 屏：欢迎 / 选菜谱 / 详情 / 做菜模式 / 我的食光）
css/
  base.css          设计变量、reset、屏幕切换、通用动画、Toast
  welcome.css       欢迎页（拍立得、涂鸦、打字机气泡样式）
  recipes.css       选菜谱页（筛选、卡片、快捷工具）
  detail.css        菜谱详情页 + 做菜模式
  modals.css        弹窗（今日灵感 / 冰箱找菜 / 做饭记录）
  mine.css          我的食光（收藏/采购/时光轴）
js/
  data.js           菜谱数据 RECIPES + 口味/主料映射 + DOM 工具
  store.js          localStorage 存储层（收藏/采购/时光轴）
  app.js            屏幕切换、菜谱页筛选交互、Toast、弹窗、转盘、冰箱找菜
  detail.js         菜谱详情页（份量换算）+ 做菜模式（计时/响铃/常亮）+ 做饭记录
  mine.js           我的食光（收藏夹 / 采购清单 / 做饭时光轴）
assets/images/      图片素材
```

## 界面特色

- 欢迎页：拍立得相框（白边 + 微倾斜 + 和纸胶带）、Ken Burns 照片慢缩放、打字机轮播气泡
- 选菜谱页：拍立得风格卡片、分类 + 菜系双筛选（均可选，菜系默认不限）
- 菜谱详情页：可勾选划掉的食材清单、编号步骤、主厨小贴士便签
- 做菜模式：全屏大字步骤翻页、自动识别"炖/焖/烤 X 分钟"一键倒计时、响铃提醒、屏幕常亮
- 手账 / 生活感设计语言，适配手机端与"减少动态效果"设置

## 说明

- 欢迎页大图为自定义美食图 `assets/images/hero-food.jpg`，替换同名文件即可换图。
- `js/app.js` 顶部的 `RECIPES` 数组是占位菜谱数据，后续接入真实菜谱时改这里。
- 农家小炒肉、韩式石锅拌饭暂用占位图（`img: null, emoji: "🌶️"`），在 `RECIPES` 里给这两条加上 `img` 字段即换回真图。
- 搜索目前为框架占位提示。
