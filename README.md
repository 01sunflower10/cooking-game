# 食光机 · 帮助你更好的做饭

一个本地运行的家常菜谱 APP：帮你决定吃什么，带你把菜做出来，并记录你做的每一顿饭。

**数据全部保存在你自己的 MySQL 数据库里**，不经过任何云服务。

---

## 一、怎么启动（日常使用看这里）

**方式 A（推荐）：双击项目文件夹里的 `食光机.exe`**
无黑窗口，自动启动服务并打开浏览器。用完在任务管理器结束「食光机.exe」，或放着不管。

**方式 B：双击「启动食光机.bat」**
有命令行窗口的版本，日志可见，方便排查问题。

用完关闭窗口/进程即可，数据已实时保存进 MySQL，不怕关。

> 前提：MySQL 服务（MySQL80）需要处于运行状态。默认安装后它是开机自启的，一般不用管。
> 如果提示"连接失败"，先确认 MySQL 在跑：任务管理器 → 服务 → 找 MySQL80 → 启动。

## 四、常见问题

**Q：怎么重新打包 食光机.exe？**
在 server 目录依次执行（需要 Node 24 和官方 node.exe，详见打包脚本历史）：
```
node --experimental-sea-config sea-config.json
copy 官方node.exe 食光机.exe
npx postject 食光机.exe NODE_SEA_BLOB sea-prep.blob --sentinel-fuse NODE_SEA_FUSE_fce680ab2cc467b6e072b8b5df1996b2
```

**Q：双击 .bat 后浏览器打开但显示"无法访问"？**
服务可能还没就绪或启动失败。看黑窗口里的报错：
- `数据库连接失败` → MySQL 没在运行，去服务里启动 MySQL80；
- `EADDRINUSE` → 端口被占用，重启电脑或关闭旧的 node 进程。

**Q：换电脑了，数据怎么迁移？**
1. 新电脑装 Node.js 和 MySQL；
2. 拷贝整个项目文件夹 + 旧电脑的数据库（用 Navicat/Workbench 导出 `shiguangji_db`，在新机导入）；
3. 新电脑运行 `server/setup-db.bat`（或直接导入库），双击启动 .bat 即可。

**Q：怎么备份数据？**
用 MySQL Workbench 连接本地库，导出 `shiguangji_db` 为 .sql 文件保存。核心就四张表：收藏、采购计划、做饭记录、自定义菜谱。

**Q：想改数据库密码/账号？**
编辑 `server/config.json`，改成新的账号密码，重启 .bat 即可（数据库里账号也要对应改）。

**Q：做的饭想留给家里人看 / 手机上用？**
目前服务只在本机。想让局域网内其他设备访问：把 `server/server.js` 里的 `app.listen(PORT)` 改为 `app.listen(PORT, "0.0.0.0")`，重启后手机连同一 WiFi 访问 `http://你电脑的IP:3000`。
